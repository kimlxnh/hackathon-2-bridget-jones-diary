# Bridget Jones Diary API

## Overview 

A diary API that allows you to add, remove, and view online diary entries.

## Getting Started

### Prerequisites 

- __Node.js__

- __npm__

- A cloud-based database management hosting platform (e.g. [Supabase](https://supabase.com/).

## How to use the API

# Viewing diary entries

When you load the website, the diary entries will automatically show.

# Adding/deleting diary entries

To add and delete diary entries, click on the `add` button or `delete` button. 

For editing of diary entries, click on the `edit` button.
